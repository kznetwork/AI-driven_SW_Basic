5.6 은 빈 폴더에서 '계획 먼저'로 시작한다.

5.7 기법 실습은 `src/lib/shorten.ts` 를 대상으로 한다. 5.6 에서 이 파일이 만들어지지 않았다면 `참고/기법실습_시작파일/` 의 내용을 linksnip1 루트로 복사한 뒤 `npm install` → `npm test` (1 passed) 를 확인하고 시작한다.
시작 코드에는 일부러 고칠 거리(같은 URL 에 다른 코드 · 빈 문자열 미검사 · 충돌 미처리)를 남겨 두었다.
