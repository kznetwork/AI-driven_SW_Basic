# linksnip

## 어디에서 실습하나 (작업 폴더)

| 항목 | 내용 |
|---|---|
| 작업 폴더 | `C:\DEV\sidebar`  (macOS: `~/DEV/sidebar`) |
| 방식 | **제공 폴더 사용** — 이 제공 폴더(`sidebar\`) 전체를 `C:\DEV\sidebar` 로 **복사**한 뒤 Codex App 에서 **'폴더 열기'**(또는 프로젝트 만들기 → 소스 폴더)로 연다. |
| 해당 교안 절 | 4장 4.2 ~ 4.4 |
| 참고 | 복사한 폴더를 Codex App 의 '새 프로젝트 → 소스 폴더'로 지정한다 (4.2 사이트 실습). |


긴 URL 을 짧은 링크로 바꿔 주는 서비스 입니다.

## 주요 기능
- 링크 단축 : 긴 주소를 6자리 코드로 줄입니다
- 클릭 통계 : 링크별 클릭 수를 확인 할 수 있습니다
- 만료일 설정 (2024년 하반기 지원 예정)

## 시작하기
```bash
npm instal
npm run dev
```
