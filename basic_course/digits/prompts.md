## 3장 · 3.4 ⑬

### ⑬ 손글씨 숫자 인식 프로그램 만들어서 실행하기
<sub>슬라이드 29–30 · 3장 · 3.4</sub>

```text
손글씨로 숫자를 입력하면 이것을 인식하는 코드를 만들어서 실행해 줘. 모든 코드와 주석을 영어로 작성해 줘.

조건:
- TensorFlow · PyTorch 같은 무거운 라이브러리는 쓰지 말고, scikit-learn 의 digits 데이터셋(8×8 손글씨)으로 만들 것
- 마우스로 숫자를 그리는 간단한 창(tkinter)에서 입력하고, 인식한 숫자를 창에 보여 줄 것
- 처음 실행할 때 모델의 정확도(%)를 터미널에 출력할 것
- 설치가 필요한 패키지가 있으면 설치 전에 무엇을 설치하는지 먼저 알려 줄 것
```

**기대 결과(요약)** 환경 확인 → scikit-learn 설치 승인 → 파이썬 파일 생성 → 실행(정확도 출력 · 그리기 창)

- 확인: 승인 창마다 내용 읽기  ▸  설치는 '이번에만 허용'  ▸  창에 숫자를 그려 인식 결과 보기

### 후속 — 정확도 · 틀리는 숫자 · 영어 주석 점검
<sub>슬라이드 31 · 3장 · 3.4</sub>

```text
방금 만든 프로그램을 다음 순서로 점검해 줘.
1) 모델 정확도를 출력하고, 가장 자주 틀리는 숫자 3개를 알려 줘
2) 내가 그린 숫자가 틀리게 인식되는 이유를 이 프로그램의 구조(8×8 축소) 기준으로 설명해 줘
3) 코드와 주석에 한국어가 남아 있으면 영어로 고치고, 고친 뒤 다시 실행해서 결과를 보여 줘
```

**기대 결과(요약)** 정확도 · 혼동되는 숫자 3개 · 틀리는 이유 설명 · 한국어 주석이 없어진 코드
