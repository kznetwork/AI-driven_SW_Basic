## 쓰는 법
- 이 폴더를 `C:\DEV\meeting` 로 복사하고, **Codex App 에서 '폴더 열기'(또는 프로젝트 만들기 → 소스 폴더)** 로 연다.
- 이 파일을 VS Code 나 메모장에 열어 두고, 코드 블록을 복사해 **Codex 작성 칸**에 붙여 넣는다.
- `@경로` 는 파일을 컨텍스트에 넣고(작성 칸에서 `@` 입력 후 검색), `$이름` 은 Skill 을 부르고, `/명령` 은 앱 · CLI 명령이다.
- 승인 창이 뜨면 **무엇을 하려는지 읽고** 허용한다. 네트워크가 필요하면 '이번에만 허용'.
- 기대 결과는 요약이다 — **응답 문구와 코드 모양은 실행마다 다르다.** 판단 기준은 파일 · 화면 · 명령 실행 결과다.

## 3장 · 3.4

### ⑪ 음성 → 텍스트

```text
[0905_회의.m4a](C:\DEV\meeting\0905_회의.m4a) 파일 내용을 텍스트로 받아 적어줘. 화자가 여러 명이면 발언자 A, B로 구분해줘.
```

**결과 예시** (응답 문구는 실행마다 다르다)

```text

  A: 이번 주 라인 점검 결과부터 볼게요.
  B: 3라인 접착 온도가 기준보다 2도 높았다.
  A: 그럼 금형 점검을 목요일로 당기죠.
  …
  0905_회의.txt 로 저장할까요?
```

- 확인: C:\DEV\meeting 의 0905_회의.m4a 로 실행  ▸  12가지 중 3가지 이상 실행했는지 스스로 확인
