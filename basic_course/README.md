## 실습 폴더는 어디에 만드나 — 한눈에

모든 실습 프로젝트는 `C:\DEV\` 아래에 둔다 (macOS: `~/DEV/`). 슬라이드 오른쪽 위의 **작업 폴더** 칸(파란색 = 새로 만들기 · 주황색 = 제공 폴더 복사 · 청록색 = 앞에서 만든 폴더 이어서 사용)과 같은 내용이다.

| 제공 폴더 | 작업 폴더 | 방식 | 교안 절 |
|---|---|---|---|
| `00_전역설정/` | `C:\Users\<사용자>\.codex` | 전역(홈 폴더) | 7.2 · 7.5 |
| `codex-hello/` | `C:\DEV\codex-hello` | 새로 만들기 | 3.2 · 3.3 · 3.5 |
| `manufacturing/` | `C:\DEV\manufacturing` | 제공 폴더 복사 | 3.4 ① ~ ⑩ |
| `meeting/` | `C:\DEV\meeting` | 제공 폴더 복사 | 3.4 ⑪ ⑫ |
| `digits/` | `C:\DEV\digits` | 새로 만들기 | 3.4 ⑬ |
| `sidebar/` | `C:\DEV\sidebar` | 제공 폴더 복사 | 4장 4.2 ~ 4.4 |
| `linksnip1/` | `C:\DEV\linksnip1` | 새로 만들기 | 5.6 · 5.7 · 5.8 |
| `linksnip2/` | `C:\DEV\linksnip2` | 새로 만들기 | 6.5 |

| `Skill/` | `C:\DEV\Skill` | 새로 만들기 | 7.7 · 7.8 |

- **새로 만들기**: 빈 폴더를 만들어 Codex App 에서 연다. 제공 폴더는 prompts.md · `참고/` 를 열어 보는 용도다.
- **제공 폴더 복사**: 제공 폴더 전체를 C:\DEV 로 복사한 뒤 연다 (데이터 파일이 들어 있다).

## 함께 들어 있는 것
- `프롬프트_템플릿.md` — 꺾쇠 `< >` 만 바꿔 실무에서 재사용하는 일반형 (P · C · T · F · 기법 8가지 · 치트시트)
- `강사용_프롬프트_모음.md` — 슬라이드 번호 순서 · 결과 예시 · 진행 메모 (수강생용 배포본에는 없음)
- 각 폴더의 `참고/` — 해당 실습이 끝난 상태의 파일 (막혔을 때 비교 · 복사용)
- `manufacturing/` 의 데이터는 실습용 가상 데이터다. `meeting/` 의 녹음 파일은 각자 준비한다.

## 프롬프트 표기
- `@경로` 파일 지정 · `$이름` Skill 호출 · `/명령` 앱 · CLI 명령 (예: /model, /permissions, /goal, /side)
- 실행 결과는 실행마다 다르다 — 교안의 실행 화면 · 결과 예시와 '구조'가 같은지를 본다.
