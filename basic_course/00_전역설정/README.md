# 00_전역설정 — 7장 7.2 · 7.5

## 어디에서 실습하나 (작업 폴더)

| 항목 | 내용 |
|---|---|
| 작업 폴더 | `C:\Users\<사용자>\.codex` |
| 방식 | **전역 설정** — 프로젝트 폴더를 만들지 않는다. |
| 해당 교안 절 | 7.2 · 7.5 |
| 참고 | 프로젝트 폴더가 아니라 홈 폴더의 .codex 에 파일을 만든다 (macOS: ~/.codex). 프롬프트는 어떤 프로젝트를 연 상태에서든 실행한다. |


이 두 파일은 프로젝트가 아니라 **홈 폴더의 .codex** 에 만든다.

| 파일 | 위치 (Windows) | 위치 (macOS) |
|---|---|---|
| AGENTS.md | C:\Users\<사용자>\.codex\AGENTS.md | ~/.codex/AGENTS.md |
| config.toml | C:\Users\<사용자>\.codex\config.toml | ~/.codex/config.toml |

prompts.md 의 프롬프트로 Codex 에 만들게 하거나, `참고/` 의 파일을 직접 복사한다. config.toml 의 model 값은 내 계정에서 쓸 수 있는 이름으로 바꾼다.
