| 항목 | 내용 |
|---|---|
| 작업 폴더 | `C:\DEV\linksnip2`  (macOS: `~/DEV/linksnip2`) |
| 방식 | **새로 만들기** — 빈 폴더 `C:\DEV\linksnip2` 를 직접 만든 뒤 Codex App 에서 **'폴더 열기'**(또는 프로젝트 만들기 → 소스 폴더)로 연다. 이 제공 폴더(`linksnip2\`)는 **열어 보는 용도**다 — prompts.md 의 프롬프트를 복사하고, 막힐 때만 `참고/` 와 비교한다 (작업 폴더로 복사하지 않는다). |
| 해당 교안 절 | 6.5 |
| 참고 | '준비' 프롬프트로 src/api/shorten.ts 를 만든다. 막히면 `참고/src` 와 비교한다. |


빈 폴더에서 '준비' 프롬프트로 src/api/shorten.ts 를 만든 뒤, `@src/api/shorten.ts` 로 콕 집어 수정을 시킨다.
