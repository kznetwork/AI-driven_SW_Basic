### ① 질의응답 (Q&A)
<sub>슬라이드 23 · 3장 · 3.4</sub>

```text
엑셀에서 VLOOKUP 함수 어떻게 쓰는지 알려줘. 예시 데이터를 만들어서 설명해줘.
```

**결과 예시** (응답 문구는 실행마다 다르다)

```text
✦ VLOOKUP 은 표의 첫 열에서 값을 찾아 같은 행의 다른 열 값을
  가져오는 함수이다.
  =VLOOKUP(찾을값, 범위, 열번호, FALSE)

  예시 데이터  A열 사번 | B열 이름 | C열 부서
  A001  김민수  생산1팀
  A002  이서연  품질팀
  =VLOOKUP("A002", A2:C10, 3, FALSE)  →  품질팀
  · 마지막 인수 FALSE = 정확히 일치하는 값만 찾기
```

- 확인: 두 프롬프트 중 하나 이상 실행  ▸  ①은 예시 표가 들어갔는지, ②는 5문장 이내인지 확인

### ⑥ 프로그램(자동화) — 다중 파일 병합
<sub>슬라이드 26 · 3장 · 3.4</sub>

```text
C:\DEV\manufacturing 폴더에 있는 다음 Excel 파일 5개를 하나의 Excel 통합문서로 합쳐줘.
- 2020-01-21_A_Line.xlsx ~ 2020-01-25_A_Line.xlsx (5개)
작업 요구사항:
1. 각 파일의 `RC` 시트 데이터를 하나의 `통합 데이터` 시트에 세로로 이어 붙여줘.
2. 첫 번째 파일의 헤더만 사용하고, 나머지 파일의 헤더 행은 제외해줘.
3. 1월 21일과 22일 파일에만 있는 `BLE DEVICENAME`, `BLE RSSI` 열도 통합 열 구조에 포함해줘.
4. 특정 파일에 없는 열은 빈 셀로 두고, 열 이름을 기준으로 정확하게 배치해줘. 열 위치만 보고 합치지 마.
5. `원본 파일` 열을 새로 추가하여 각 행이 어느 파일에서 왔는지 기록해줘.
6. 날짜와 시간, 숫자, 제품 시리얼 및 MAC 주소의 데이터 형식을 보존해줘.
7. 전체 데이터에 필터를 적용하고 첫 번째 행을 고정해줘.
8. 중복 데이터는 임의로 삭제하지 말고 모두 유지해줘.
9. 별도의 `통합 요약` 시트에 원본 파일별 · 날짜별 · 검사 결과(`Result`)별 · 전체 데이터 건수를 정리해줘.
10. 원본 파일별 데이터 건수를 비교하는 막대 차트를 `통합 요약` 시트에 추가해줘.
11. 수식 오류와 누락 여부를 검사하고, 원본 파일별 행 수의 합계가 통합 데이터 행 수와 일치하는지 확인해줘.
12. 원본 파일은 변경하지 말고 결과를 C:\DEV\manufacturing\A_Line_통합_검사기록.xlsx 로 저장해줘.
```

**결과 예시** (응답 문구는 실행마다 다르다)

```text
✦ A_Line_통합_검사기록.xlsx 를
  만들었다.

  통합 데이터  1,250행
  · 01-21  250  · 01-22  250
  · 01-23  250  · 01-24  250
  · 01-25  250
  BLE 열 2개 포함
  (01-23~25 는 빈 셀)

  검증
  · 원본 합계 1,250
    = 통합 1,250  ✓
  · 수식 오류 0건
  · 원본 파일 변경 없음
```

- 확인: C:\DEV\manufacturing 열기  ▸  아래 프롬프트 전송  ▸  A_Line_통합_검사기록.xlsx 의 '통합 요약' 시트와 행 수 일치 여부 확인
- 참고: 막히면 요구사항 번호를 줄여(1~5번만) 먼저 실행하고, 나머지를 후속 지시로 붙인다.
