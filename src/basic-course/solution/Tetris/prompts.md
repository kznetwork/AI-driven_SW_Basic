## 9장 · 9.1

### Tetris PRD.md 작성
<sub>슬라이드 109 · 9장 · 9.1</sub>

```text
아래 내용을 PRD.md로 작성해줘.

# PRD — Tetris
## 1. 한 줄 요약
브라우저에서 바로 플레이할 수 있는 간단한 싱글 플레이어 테트리스 게임.
## 2. 문제 / 목표
- 목표: 기본적인 테트리스 게임 규칙을 구현한다.
- 사용자는 설치나 로그인 없이 브라우저에서 즉시 게임을 시작할 수 있다.
- 키보드를 이용하여 블록을 이동하고 회전시킬 수 있다.
## 3. 핵심 사용자 시나리오
1. 사용자가 게임 페이지를 연다.
2. 게임이 시작되면 블록이 위에서 아래로 떨어진다.
3. 사용자는 키보드로 블록을 이동하거나 회전한다.
4. 블록이 바닥이나 다른 블록과 충돌하면 고정된다.
5. 한 줄이 완성되면 해당 줄이 제거된다.
6. 줄 제거에 따라 점수가 증가한다.
7. 블록이 게임 보드 상단까지 쌓이면 게임이 종료된다.
8. 사용자는 Restart 버튼으로 게임을 다시 시작할 수 있다.
## 4. 기능 요구사항 (MVP)
- [F1] 10 × 20 게임 보드 생성
- [F2] 7종 Tetromino 생성
- [F3] 블록 자동 하강
- [F4] 좌우 이동
- [F5] 블록 회전
- [F6] Soft Drop
- [F7] 벽과 다른 블록에 대한 충돌 감지
- [F8] 블록 고정
- [F9] 완성된 라인 제거
- [F10] 점수 계산
- [F11] Game Over 판정
- [F12] Restart 기능
## 5. 비기능 요구사항
- 데스크톱 브라우저에서 정상 동작
- 입력에 즉각적으로 반응할 것
- 게임 로직과 UI를 가능한 한 분리할 것
- 핵심 게임 로직을 테스트할 수 있는 구조로 작성할 것
- 외부 유료 서비스에 의존하지 않을 것
## 6. 범위 제외
이번 MVP에서는 다음 기능을 구현하지 않는다.
- 사용자 로그인 · 온라인 멀티플레이 · 랭킹 서버
- 아이템 · Hold 기능 · Ghost Piece
- 모바일 터치 컨트롤 · 사운드 효과
위 기능은 이후 버전에서 추가할 수 있다.
## 7. 성공 기준
- 7종 Tetromino가 정상적으로 생성된다.
- 블록 이동과 회전이 정상 동작한다.
- 충돌 시 블록이 정확한 위치에 고정된다.
- 완성된 라인이 정상적으로 제거된다.
- 점수가 정상적으로 증가한다.
- Game Over 조건이 정상적으로 동작한다.
- Restart 후 게임 상태가 초기화된다.
```

## 10장 · 10.3

### 품질관리 Skill 7개를 Codex 로 한 번에 만들기
<sub>슬라이드 115 · 10장 · 10.3</sub>

```text
.agents/skills/ 아래에 아래 목록의 품질관리 skill 을 각각 SKILL.md 로 만들어줘.
공통 규칙:
- 폴더명과 name 은 이름에서 앞의 "$"를 뗀 소문자 · 하이픈 형태로 한다(예: $code-review → code-review).
- description 에는 "무엇을 점검하는지"와 "언제 호출하는지"를 한 문장으로 적는다.
- 본문에는 각 skill 의 확인 기준을 점검 체크리스트로 옮기고, 항목마다 통과/실패 판정 기준을 한 줄씩 붙인다.
- 원칙적으로 코드를 직접 고치지 말고, 발견한 문제를 "항목 / 심각도(높음 · 중간 · 낮음) / 개선안" 표로 보고한다.
- 예외: refactor-safe 는 기능과 공개 API 를 바꾸지 않는 선에서 리팩터링을 직접 수행하고, 변경 전후로 테스트가 모두 통과함을 보여 준다.
만들 skill:
- review-structure : 파일 구조, 역할 분리, 실행 가능성
- code-review : DOM 구조, 렌더링 함수, 가독성
- review-game-logic : 충돌 판정, 경계값, 회전 오류
- qa-playtest : 사용자 시나리오별 기대 결과(예: 4줄=800점, 게임오버 후 재시작)
- bug-hunt : 고위험 버그 탐지 및 우선순위화
- refactor-safe : 기능 변화 없는 구조 개선
- release-check : 파일 연결, 실행법, GitHub Pages 설정
끝나면 생성한 폴더 트리와 각 SKILL.md 의 name · description 을 표로 요약해서 보여줘.
```

**결과 예시** (응답 문구는 실행마다 다르다)

```text

  code-review        DOM · 렌더링 · 가독성 점검
  review-game-logic  충돌 · 경계값 · 회전 점검
  qa-playtest        시나리오별 기대 결과 점검
  bug-hunt           고위험 버그 우선순위화
  refactor-safe      기능 불변 리팩터링 수행
  release-check      배포 전 최종 점검
```
