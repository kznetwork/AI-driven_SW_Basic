```text
  =VLOOKUP("A002", A2:C10, 3, FALSE)  →  품질팀
  · 마지막 인수 FALSE = 정확히 일치하는 값만 찾기
```

## 9. ⑥ 프로그램(자동화) — 다중 파일 병합
<sub>슬라이드 26 · 3장 · 3.4 | 유형별 대화 ⑥ · 폴더 manufacturing</sub>

```text
C:\DEV\manufacturing 폴더에 있는 다음 Excel 파일 5개를 하나의 Excel 통합문서로 합쳐줘.
- 2020-01-21_A_Line.xlsx ~ 2020-01-25_A_Line.xlsx (5개)
작업 요구사항:
1. 각 파일의 `RC` 시트 데이터를 하나의 `통합 데이터` 시트에 세로로 이어 붙여줘.
2. 첫 번째 파일의 헤더만 사용하고, 나머지 파일의 헤더 행은 제외해줘.

5. `원본 파일` 열을 새로 추가하여 각 행이 어느 파일에서 왔는지 기록해줘.
6. 날짜와 시간, 숫자, 제품 시리얼 및 MAC 주소의 데이터 형식을 보존해줘.
7. 전체 데이터에 필터를 적용하고 첫 번째 행을 고정해줘.
```

## 52. Tetris PRD.md 작성

```text

# PRD — Tetris
## 1. 한 줄 요약
브라우저에서 바로 플레이할 수 있는 간단한 싱글 플레이어 테트리스 게임.
## 2. 문제 / 목표
- 목표: 기본적인 테트리스 게임 규칙을 구현한다.
- 사용자는 설치나 로그인 없이 브라우저에서 즉시 게임을 시작할 수 있다.
- 키보드를 이용하여 블록을 이동하고 회전시킬 수 있다.
## 3. 핵심 사용자 시나리오
1. 사용자가 게임 페이지를 연다.
2. 게임이 시작되면 블록이 위에서 아래로 떨어진다.
3. 사용자는 키보드로 블록을 이동하거나 회전한다.
4. 블록이 바닥이나 다른 블록과 충돌하면 고정된다.
5. 한 줄이 완성되면 해당 줄이 제거된다.
6. 줄 제거에 따라 점수가 증가한다.
7. 블록이 게임 보드 상단까지 쌓이면 게임이 종료된다.
8. 사용자는 Restart 버튼으로 게임을 다시 시작할 수 있다.
## 4. 기능 요구사항 (MVP)
- [F1] 10 × 20 게임 보드 생성
- [F2] 7종 Tetromino 생성
- [F3] 블록 자동 하강
- [F4] 좌우 이동
- [F5] 블록 회전
- [F6] Soft Drop
- [F7] 벽과 다른 블록에 대한 충돌 감지
- [F8] 블록 고정
- [F9] 완성된 라인 제거
- [F10] 점수 계산
- [F11] Game Over 판정
- [F12] Restart 기능
## 5. 비기능 요구사항
- 데스크톱 브라우저에서 정상 동작
- 입력에 즉각적으로 반응할 것
- 게임 로직과 UI를 가능한 한 분리할 것
- 핵심 게임 로직을 테스트할 수 있는 구조로 작성할 것
- 외부 유료 서비스에 의존하지 않을 것
## 6. 범위 제외
이번 MVP에서는 다음 기능을 구현하지 않는다.
- 사용자 로그인 · 온라인 멀티플레이 · 랭킹 서버
- 아이템 · Hold 기능 · Ghost Piece
- 모바일 터치 컨트롤 · 사운드 효과
위 기능은 이후 버전에서 추가할 수 있다.
## 7. 성공 기준
- 7종 Tetromino가 정상적으로 생성된다.
- 블록 이동과 회전이 정상 동작한다.
- 충돌 시 블록이 정확한 위치에 고정된다.
- 완성된 라인이 정상적으로 제거된다.
- 점수가 정상적으로 증가한다.
- Game Over 조건이 정상적으로 동작한다.
- Restart 후 게임 상태가 초기화된다.
```
