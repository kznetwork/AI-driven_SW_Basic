# Tetris

브라우저에서 바로 즐길 수 있는 클래식 테트리스 게임입니다. 7종의 테트로미노를 이동하고 회전해 가로줄을 완성하고, 점수를 높여 보세요.

## 데모

[GitHub Pages에서 플레이하기](<여기에 링크>)

## 주요 기능

- 10 × 20 게임 보드
- 7종 테트로미노와 다음 블록 미리보기
- 완성된 줄 제거 및 점수 계산
- 진행에 따른 레벨 상승과 낙하 속도 증가
- 게임 오버 및 다시 시작

## 조작법

| 키 | 동작 |
| --- | --- |
| `←` / `→` | 블록을 왼쪽 / 오른쪽으로 이동 |
| `↓` | 블록을 한 칸 빠르게 내리기 |
| `↑` | 블록 회전 |
| `Space` | 블록 즉시 내리기 |

## 실행 방법

별도의 설치 과정 없이 `index.html`을 웹 브라우저에서 열면 실행할 수 있습니다.
