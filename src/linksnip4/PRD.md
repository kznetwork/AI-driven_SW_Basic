# PRD — LinkSnip

## 1. 한 줄 요약

긴 URL을 6자리 짧은 링크로 바꿔 주는, 로그인 없이 바로 쓰는 웹 서비스.

## 2. 문제 / 목표

- 문제: 긴 URL은 공유·인쇄·기억이 불편하다.
- 목표: 누구나 3초 안에 링크를 줄이고 복사할 수 있게 한다.

## 3. 핵심 사용자 시나리오

1. 사용자가 긴 URL을 입력하고 "줄이기"를 누른다.
2. 6자리 코드가 붙은 짧은 링크(예: `https://snip.example/aB3xY9`)를 받는다.
3. "복사" 버튼으로 클립보드에 복사한다.
4. 그 짧은 링크로 접속하면 원래 URL로 이동(리다이렉트)된다.

## 4. 기능 요구사항 (MVP)

- [F1] URL 입력 + 유효성 검사(http/https만 허용)
- [F2] 6자리 코드 생성 및 KV 저장(코드 → 원본 URL)
- [F3] `/:code` 접속 시 원본 URL로 302 리다이렉트
- [F4] 결과 링크 복사 버튼
- [F5] 잘못된 입력/없는 코드에 대한 에러 화면

## 5. 비기능 요구사항

- 모바일에서도 보기 좋은 반응형 UI
- 응답 1초 이내, 외부 유료 의존성 없이 무료 한도로 운영

## 6. 이번 범위에서 제외(Out of scope)

- 회원가입/로그인, 커스텀 도메인, 만료 기능(추후)

## 7. 성공 지표

- 링크 생성 성공률 99% 이상, 리다이렉트 오류율 1% 미만
