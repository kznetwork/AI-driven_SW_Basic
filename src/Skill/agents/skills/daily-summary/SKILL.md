# Daily Summary

사용자가 제공한 메모만 사용해 한국어 업무 보고를 작성한다.

## 작성 형식

- 완료
- 다음 작업
- 이슈

각 항목은 짧은 글머리표로 작성한다.

내용이 없는 항목에는 `없음`이라고 쓴다.
메모에 없는 사실, 일정 또는 담당자를 추측해서 추가하지 않는다.
중복된 내용은 하나로 합친다.
